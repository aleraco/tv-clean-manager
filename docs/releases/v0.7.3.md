## What changed since v0.7.2

- **Guided mode** continues to restrict write actions to the device/package profiles explicitly supported by the application.
- **Advanced mode** is an explicit, acknowledged opt-in for disabling unknown packages that are **not classified as critical**, one unknown package at a time.
- **Enable selected** can enable an already disabled package even if it was disabled previously with manual ADB or a different application.
- **Restore journal** remains a distinct workflow that attempts to reverse actions recorded by TV Clean Manager.
- The application checks device identity before write operations and requires a diagnostic backup and local journal.
- Known critical packages and sensitive package families remain protected.
- Community reports are **informational**: they do not automatically authorize writes or override protections.

## Important limitations

**Advanced mode is risky.** The critical-package classification is not complete for every Android TV / Google TV device or firmware. Packages not identified as protected may still be essential. Disabling a package can cause loss of TV features, inability to boot, or loss of ADB access. In some cases, recovery may be impossible through this application.

Diagnostic backups are **not firmware images** and do not guarantee recovery. Re-enabling a package is not necessarily equivalent to undoing all changes made by external tools.

A successful GUI test is not proof that modifying or restoring any particular package is safe. **Do not experiment on the TV launcher, boot components, network/ADB services, Android system packages, or essential television services.**
