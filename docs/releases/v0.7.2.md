# TV Clean Manager v0.7.2 — GUI / DPI improvements

**Status:** the project author confirmed the **v0.7.2 test build is working on their Windows PC** (14 November 2026). This confirms the reported GUI problem was resolved in that test; it is **not** a claim of multi-device compatibility or tested system-package restoration.

The public release is still [v0.7.0 Beta](https://github.com/aleraco/tv-clean-manager/releases/tag/v0.7.0) until the newer application ZIP is uploaded to a new GitHub Release.

## Changes in the verified test build

- DPI-aware Windows Forms layout, with control sizes adjusted for display scaling.
- Text-measured button and label widths in Italian and English to avoid truncation.
- Reorganized connection controls, package actions and filters.
- Improved table row spacing and empty-state guidance.
- Better scaling and scrolling for secondary dialogs and the technical log.
- Limit the application window to the available desktop work area.
- Record layout errors under `%LOCALAPPDATA%\TVCleanManager\logs`.

The build includes the v0.7.2 sources supplied by the project author and carries over the bundled ADB tools and `simulator.ps1` from v0.7.0. There were **no intentional changes to device-writing behavior, safety restrictions or package profiles**.
